Here are some of the project details in multiple industries.


#### Improving Telecom Customer Experience by Complaint Prediction
1. Developed a machine learning model to predict subscribers likely to complain within the next three days. Allowed business to proactively improve the system.
2. Conducted exploratory data analysis (EDA) on CRM data and network KPI metrics to gain domain insights and identify trends.
3. Applied interpolation and outlier detection techniques to preprocess features and performed feature selection for optimal model inputs.
Trained and optimized XGBoost and Decision Tree classifiers to predict complaint likelihood and categorize complaint types, incorporating rule-based post-processing.
4. Achieved a 0.7 F1 score for the model and deployed the end-to-end pipeline in Kubernetes pods.





#### Disease Risk Profiling
1. Identified vulnerable individuals and regions to help businesses raise awareness and recommend preventive actions to government bodies.
2. Analyzed domain data to extract key features, including comorbidity scores, travel/medical history, vaccination status, and blood reports.
3. Preprocessed features using data imputation and class imbalance handling techniques.
4. Built a Random Forest classifier for binary classification, using probability scores to assess risk for locations and individuals, and implemented score categorization for improved insights.
5. Retrieved data from GCP BigQuery, trained models using Vertex AI Notebooks, and deployed APIs via Vertex AI for real-time serving.

#### Length of Stay Prediction
1. Developed a predictive model to optimize medical equipment management in emergency hospital facilities.
2. Conducted feature engineering and preprocessing for imbalanced data using KBinsDiscretizer, imputation techniques, and data cleansing.
3. Implemented a hierarchical modeling approach to predict same-day discharges versus extended stays using algorithms like XGBoost and Decision Trees.
4. Achieved 70% prediction accuracy with a 1-day error rate; enhanced model performance by consolidating categories with day margins.
5. Retrieved data from GCP BigQuery, built the model in Vertex AI Notebooks, and deployed it via Vertex AI APIs for seamless integration and scalability.
