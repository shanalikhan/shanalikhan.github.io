Here are selected projects highlighting expertise in time series analysis:


#### Restaurant Optimisation (Sales Forecast & Recommendation)
1. Developed a predictive sales forecasting model to estimate next-day part and weekly sales, enabling restaurants to optimize meal preparation and employee scheduling.
2. Conducted Exploratory Data Analysis (EDA) to identify key features, including temporal patterns, sales trends, weather, and competitors, and applied data preprocessing techniques like spline interpolation and outlier removal using IQR.
3. Implemented machine learning models (ARIMA, SARIMA, AdaBoost, Ridge Regression) and applied an ensemble stacking approach to enhance forecasting accuracy.
4. Achieved up to 50% reduction in food wastage and increased revenue through efficient employee rotation, calculated via ROI analysis.
5. Trained K-Means clustering for customer segmentation using unsupervised learning, selecting top features such as weather, daypart, and age for cluster formation. 
6. Conducted Market Basket Analysis with the FPGrowth algorithm to derive association rules for specific customer clusters, optimizing order recommendations.
7. Evaluated the recommendation engine using metrics like Recall and Precision@3 and analyzed its ROI and sales impact.
8. Deployed association rules and cluster dictionaries on AWS ElastiCache, consumed via production APIs hosted on AWS Fargate. Delivered the end-to-end solution using AWS Databricks with PySpark for feature engineering, job orchestration, and model deployment on a distributed cluster.
